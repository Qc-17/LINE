## 🇮🇹 Italiano

### Cos'è LINE?

LINE è un linguaggio di programmazione interpretato progettato per essere **semplice da comprendere, facile da apprendere e naturale da leggere**, mantenendo al tempo stesso le strutture fondamentali della programmazione.

Le keyword sono verbose e nominative: ogni costrutto cerca di rendere esplicita la propria funzione, così che il codice possa essere letto e compreso anche da chi si avvicina per la prima volta alla programmazione.

Un programma LINE viene salvato in un file con estensione `.line` ed eseguito tramite un interprete JavaScript direttamente nel browser, senza necessità di installazione.

### Caratteristiche

- Sintassi leggibile e orientata alla chiarezza
- Variabili e strutture di controllo
- Funzioni e moduli
- Liste e cicli
- Gestione degli errori
- Integrazione con HTML tramite **LINE-DOM**
- Rendering di espressioni matematiche
- Rendering di formule e strutture chimiche
- IDE e interprete disponibili direttamente nel browser

### Specifica LINE 3.0

Il progetto è attualmente in una fase di revisione e consolidamento della specifica di **LINE 3.0**.

Il lavoro si concentra su quattro obiettivi principali:

1. **Standardizzazione del rendering**  
   Rendere i sistemi di rendering più coerenti e, dove possibile, basati su standard e tecnologie consolidate.

2. **Controllo della coerenza del linguaggio**  
   Analizzare la sintassi esistente, eliminare ridondanze e semplificare i costrutti mantenendo chiara la semantica del linguaggio.

3. **Ottimizzazione e rafforzamento dell'interprete JavaScript**  
   Migliorare struttura, robustezza, gestione degli errori e prestazioni del motore di interpretazione.

4. **Miglioramento dell'interfaccia**  
   Rendere IDE, sito e strumenti di apprendimento più intuitivi, moderni e adatti all'utilizzo didattico.

L'obiettivo non è semplicemente aggiungere nuove funzionalità, ma **rafforzare le fondamenta di LINE** e definire una specifica più coerente e solida.

## 🇬🇧 English

### What is LINE?

LINE is an interpreted programming language designed to be **simple to understand, easy to learn, and natural to read**, while still providing the fundamental structures of programming.

Its keywords are verbose and nominative: each construct is designed to make its purpose explicit, allowing code to remain understandable even for people approaching programming for the first time.

A LINE program is saved in a `.line` file and executed through a JavaScript interpreter directly in the browser, with no installation required.

### Features

- Readable, clarity-oriented syntax
- Variables and control structures
- Functions and modules
- Lists and loops
- Error handling
- HTML integration through **LINE-DOM**
- Mathematical expression rendering
- Chemical formula and structure rendering
- Browser-based IDE and interpreter

### LINE 3.0 Specification

The project is currently undergoing a revision and consolidation of the **LINE 3.0 specification**.

Development is focused on four main goals:

1. **Rendering standardization**  
   Making the rendering systems more consistent and, where possible, based on established standards and technologies.

2. **Language consistency**  
   Reviewing the existing syntax, removing redundancies, and simplifying constructs while keeping the language's semantics clear.

3. **JavaScript interpreter optimization and reinforcement**  
   Improving the interpreter's architecture, robustness, error handling, and performance.

4. **Interface improvement**  
   Making the IDE, website, and learning tools more intuitive, modern, and suitable for educational use.

The goal is not simply to add more features, but to **strengthen LINE's foundations** and establish a more coherent and solid specification.

### Contribute

LINE is an open-source project, and development of the new specification is open to collaboration.

You can contribute through:

- interpreter development;
- syntax design and review;
- rendering systems;
- IDE development;
- documentation;
- examples and educational material;
- bug reports and improvement proposals.

You do not need to contribute to every area: even a single improvement can help the project.
